# Workflow map

This ChatGPT skill consolidates the source pack's eleven commands into one naturally triggered skill:

| User task | Workflow |
| --- | --- |
| Script, opening line, idea to video | Five hook options, best two, timed script, screen action and payoff |
| Title and thumbnail | Three truthful paired options; check readability and duplication |
| Edit this transcript | EDL for gaps, filler, and repeated takes |
| Sort/reply to comments | Categorize and draft; never auto-post |
| Plan my week | Realistic publishing schedule tied to one test per idea |
| Find trending videos | Public research and performance-versus-channel-median comparison |
| Read Studio retention | Hook loss, sharp drops, steady slide, one fix |
| Cut Shorts from a long video | Self-contained candidate moments, timecodes, new opening |
| SEO and tags | Search-focused first two lines, few relevant tags, three queries |
| Add chapters | Validate timestamps and retitle draft labels |
| Audit my channel | One main fix, specific wins, one thing to preserve |

## Helpful user inputs

- A public channel or video URL for a public-facing audit or trend scan.
- A transcript or captions file for edit, chapters, or Short selection.
- A YouTube Studio CSV export for retention analysis.
- Title and thumbnail text/image together for packaging review.
- For a weekly plan: time available and desired number of uploads.

Ask only for missing information that changes the answer. Never demand a full voice profile before giving useful first-pass work.
